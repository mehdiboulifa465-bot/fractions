📘 Rappel de cours
Produit : $$\frac{a}{b}\times\frac{c}{d}=\frac{a\times c}{b\times d}$$
Signes : nombre pair de facteurs négatifs : $+$ ; impair : $-$.
Entier : $a=\dfrac{a}{1}$.
Quotient : $$\frac{a}{b}\div\frac{c}{d}=\frac{a}{b}\times\frac{d}{c}$$
Grande barre = division (la barre la plus épaisse est la principale).
Simplifier avant de multiplier : $$\frac{6}{35}\times\frac{14}{9}=\frac{2\times3}{5\times7}\times\frac{2\times7}{3\times3}=\frac{4}{15}$$
